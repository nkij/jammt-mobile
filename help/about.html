JamMt - Just another mode matching tool

Version 0.24



JamMt is the java port of Andre Thuerings program GROB, which was developed to Get Rid Of Bps. For those of you who don't know BPS, never mind and never use it!
The aim of JamMt/Grob is to provide an easy to use tool for mode matching purposes.
