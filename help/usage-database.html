Databases

Database files can be used to store and distribute predefined substrates, lenses and materials. These files have essentially the same syntax as the .jam files (Xml) but contain only a reduced set of elements. The file extension for JamMt database files is ".jamDB".

The administration of databases is done by using the "Database manager" from the "Tools" menu. With this tool you can create a new database or import an existing one. By default, databases are "enabled" which means that they are stored in JamMt's startup folder. That means that these databases are ready to use at every start of the application. Within the database manager you can also edit or completely remove databases.

Finally, the export option lets you copy the database to a user defined file which can then be distributed.
